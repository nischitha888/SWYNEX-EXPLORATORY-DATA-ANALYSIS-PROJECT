# SWYNEX-EXPLORATORY-DATA-ANALYSIS-PROJECT
TASK-2: SWYNEX EXPLORATORY DATA ANALYSIS


## 📌 Project Overview

This project focuses on analyzing an employee dataset using Python and data visualization techniques. The dataset was explored to understand employee demographics, salaries, skills, leave patterns, employment status, regions, and work locations.

The analysis was performed using Python libraries such as **Pandas** and **Matplotlib** to clean, analyze, and visualize the data.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze employee information and demographics
- Compare employee salaries across different job roles
- Understand employee distribution by age and gender
- Analyze gender ratio
- Examine leave taken by employees
- Compare employees across different regions
- Identify common employee skills
- Analyze employment status
- Understand employee distribution by work location
- Present insights through clear visualizations

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Dataset
- Data Analysis
- Data Visualization

# 📈 Data Visualizations & Insights

## 1. 💰 Total Employee Salaries by Job Role

This pie chart shows the total salary amount associated with each job role.

**Insights:**
- HR Specialists have the highest total salary at approximately **₹15.74 lakh**.
- Managers have a total salary of approximately **₹13.69 lakh**.
- Developers have a total salary of approximately **₹12.59 lakh**.
- Designers have a total salary of approximately **₹11.41 lakh**.
- Analysts have the lowest total salary at approximately **₹9.91 lakh**.

![Total Employee Salaries by Job Role](emploees%20salaries%20image.png)

## 2. 👥 Employees by Age Range and Gender

This bar chart compares the number of male and female employees across different age groups.

# 🔍 Key Findings

The analysis provides several useful observations:

- HR Specialists have the highest total salary among the listed job roles.
- The employee gender distribution is almost equal.
- The 36–45 age group has the highest male employee count.
- The 26–35 age group has the highest female employee count.
- Managers have the highest total leave taken.
- The Central region has the largest employee population.
- Design is the most common skill, followed by Python.
- Full-time employees represent the largest employment-status group.
- Branch Offices have the highest number of employees.
